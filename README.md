# Drama Roleplay Demo

这是我四个月 AI 创作工具路线中的第三个阶段：在青蓝写作和 TBird Roundtable Box 之后，继续探索“内容不只被阅读，也可以被用户进入和参与”。后续的 [NovelX](https://github.com/ccbili30-collab/novelx) 和 [CreatX](https://github.com/ccbili30-collab/CreatX) 会把这条路线扩展到长期小说创作与更完整的交互作品。

一个面向演示的短剧转互动剧情 MVP。

它不是“真实解析任意短视频”的产品，而是一个固定样片、固定剧情、固定跑团入口的体验原型。我们现在只需要把同一条演示短剧，稳定地包装成“看完视频后随时入戏”的 AIGalgame。

## 本地启动

```powershell
npm run serve
```

打开：

```text
http://127.0.0.1:8787/
```

也可以直接模拟“外部传入链接”的演示入口：

```text
http://127.0.0.1:8787/?url=https://v.douyin.com/your-demo-link/
```

注意：

- 页面会显示“已收到链接”
- 但不会真实解析这个链接
- 无论传什么，都会统一映射到内置演示视频与预设五幕剧情

## 当前交互

- 先播放固定的演示短剧视频
- 播放结束后出现“上滑入戏”
- 上滑后进入一个明确标注为演示模式的假解析流程
- 假解析完成后进入五幕式视觉小说 / 互动剧情
- 每一幕都可以点击选项，或自己输入自由行动
- 可勾选随身道具，道具会和你的行动一起影响结果文案与数值

## 演示边界

- 不抓取真实短视频
- 不解析未知 URL
- 不接真实支付
- 不做真实 AI 剧情生成
- 重点只验证一件事：短剧结尾之后，用户能不能被顺滑带进可玩的互动剧情

## 后续方向

- 把五幕进一步做成关卡树，而不是单线演示
- 为每一幕增加更强的分支反馈和成长感
- 把“固定演示模板”替换成真正可配置的多模板入口
- 再决定是否值得接真实解析能力
